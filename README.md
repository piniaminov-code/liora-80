# liora-80

עמוד ברכה ושיר לכבוד יום ההולדת ה-80 של ליאורה. דף סטטי אחד, בעברית ומימין לשמאל, שנבנה בעיקר לצפייה בטלפון.

## קבצים
- `index.html` – מבנה העמוד
- `style.css` – עיצוב
- `data.js` – מילות השיר המאושרות ותזמון של 154 מילים (לא לשנות בלי לתזמן מחדש)
- `app.js` – נגן, קריוקי (הדגשת מילים), מצבי טעינה ושגיאה
- `photos.js` – מציג התמונות במסך מלא
- `birthday.mp4` – השיר עם הסרטון, `garden.jpg` – תמונת הפתיחה של הסרטון
- `narration.mp3` – הקראת המילים
- `photos/` – התמונות מהחגיגה

## הרצה מקומית
כדי שהקפיצה בתוך הסרטון תעבוד, השרת צריך לתמוך בבקשות Range (GitHub Pages תומך):

```bash
npx http-server -p 8080
```
